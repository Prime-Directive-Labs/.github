# 🛡️ Prime Directive Labs - Organization Configuration

This is the **`.github`** repository for [Prime Directive Labs](https://github.com/Prime-Directive-Labs).

## Purpose

This repository contains:

- **Organization Profile README** (`profile/README.md`) — Displayed on our GitHub organization page
- **Default Community Health Files** — Applied to all repositories that don't have their own
- **Shared GitHub Actions Workflows** — Reusable workflows for CI/CD
- **Organization Assets** — Logos, banners, and branding materials

## Structure

```
.github/
├── profile/
│   └── README.md          # Organization profile (shown on github.com/Prime-Directive-Labs)
├── assets/
│   └── prime-directive-banner.png
├── ISSUE_TEMPLATE/        # Default issue templates
├── PULL_REQUEST_TEMPLATE/ # Default PR templates
├── workflow-templates/    # Reusable GitHub Actions
├── FUNDING.yml            # Sponsorship configuration
├── CONTRIBUTING.md        # Default contributing guide
├── CODE_OF_CONDUCT.md     # Default code of conduct
├── SECURITY.md            # Default security policy
└── README.md              # This file
```

## Community Health Files

Files placed here serve as **defaults** for all repositories in the organization that don't have their own versions.

| File | Purpose |
|------|---------|
| `CODE_OF_CONDUCT.md` | Community behavior standards |
| `CONTRIBUTING.md` | How to contribute to our projects |
| `SECURITY.md` | Security vulnerability reporting |
| `FUNDING.yml` | Sponsorship/funding links |

## Workflow Templates

Reusable GitHub Actions workflows are in `workflow-templates/`. Repositories can use these as starting points for their CI/CD.
