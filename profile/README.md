## 🌌 The Vision

> *"Build systems that outlast their creators and serve humanity's long-term flourishing."*

Prime Directive Labs is developing **Sentinel Systems** — domain-specific AI-driven coordination networks that operate autonomously to address humanity's most critical infrastructure needs. Our approach combines:

- **🔗 Decentralized Governance** — Power distributed, not concentrated
- **⏳ Longevity Engineering** — Systems designed for centuries, not quarters
- **🤖 Autonomous Coordination** — Self-governing, minimal human intervention
- **🌍 Universal Accessibility** — Open to all, barriers minimized

## 🎯 Current Focus: Aeternos Protocol

**Aeternos** is our first Sentinel System — the coordination layer that powers the entire ecosystem:

- **🏛️ AeternosGovernor** — On-chain governance with proposal creation, voting, and execution
- **🛡️ Guard Vault** — Staking mechanism for participation and rewards
- **🎫 Sentinel Origin Pass** — NFT-based access to governance and early ecosystem benefits
- **💰 AET Token** — Native utility token for the Prime Directive ecosystem

### Deployed on Base Network

All smart contracts are deployed and verified on **Base Sepolia** (testnet) with mainnet deployment planned for Q1 2026.

## 🤝 Contributing

We welcome contributions from builders who share our vision. See our [Contributing Guide](https://github.com/Prime-Directive-Labs/primedir-workspace/blob/main/CONTRIBUTING.md) to get started.

### Development Setup

```bash
# Clone the workspace
git clone git@github.com:Prime-Directive-Labs/primedir-workspace.git
cd primedir-workspace

# Clone all repositories
./scripts/clone-all.sh

# Start development environment
docker-compose up -d

# Access points:
# 🚀 Dashboard: http://localhost:3002
# 🌐 Website:   http://localhost:3003
# ⚙️ API:       http://localhost:8000
```
